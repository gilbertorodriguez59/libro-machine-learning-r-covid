5  Regresión logística para clasificación

NotaConexión con el volumen teórico

La formulación matemática de regresión logística, máxima verosimilitud y clasificación probabilística se desarrolla con mayor profundidad en los capítulos 3, 6 y 11 de Fundamentos Matemáticos del Aprendizaje Automático (Rodríguez Escobedo 2026).

5.1 Objetivos del capítulo

Al finalizar este capítulo, el lector será capaz de ajustar una regresión logística, predecir probabilidades y evaluar el desempeño.

5.2 Fundamento matemático

La regresión logística utiliza la función:

\[ p = \frac{1}{1 + e^{-z}} \]

donde \(z = \beta_0 + \beta_1x_1 + \cdots + \beta_px_p\).

5.3 Visualización de la función logística

La curva tiene forma de S. Valores negativos producen probabilidades cercanas a cero y valores positivos probabilidades cercanas a uno.

5.11 Laboratorio interactivo: regresión logística

Explora cómo el intercepto, la pendiente y el umbral cambian la probabilidad estimada y la clasificación final.

#| '!! shinylive warning !!': |
#|   shinylive does not work in self-contained HTML documents.
#|   Please set `embed-resources: false` in your metadata.
#| standalone: true
#| viewerHeight: 720
#| components: [viewer]

library(shiny)

sigmoide <- function(z) {
  1 / (1 + exp(-z))
}

ui <- fluidPage(
  titlePanel("Laboratorio de regresión logística"),

  sidebarLayout(
    sidebarPanel(
      sliderInput("b0", "Intercepto", -10, 10, -3, 0.25),
      sliderInput("b1", "Pendiente", -5, 5, 1.2, 0.1),
      sliderInput("umbral", "Umbral de clasificación", 0.05, 0.95, 0.5, 0.05),
      sliderInput("xnew", "Valor nuevo de x", -5, 10, 2.5, 0.1)
    ),

    mainPanel(
      plotOutput("curva", height = "440px"),
      verbatimTextOutput("resultado"),
      textOutput("interpretacion")
    )
  )
)

server <- function(input, output, session) {

  prob_nueva <- reactive({
    sigmoide(input$b0 + input$b1 * input$xnew)
  })

  output$curva <- renderPlot({
    x <- seq(-5, 10, length.out = 400)
    p <- sigmoide(input$b0 + input$b1 * x)

    plot(
      x, p,
      type = "l",
      lwd = 3,
      ylim = c(0, 1),
      xlab = "Variable x",
      ylab = "Probabilidad estimada",
      main = "Curva logística y umbral"
    )

    abline(h = input$umbral, lty = 2)
    abline(v = input$xnew, lty = 3)

    points(
      input$xnew,
      prob_nueva(),
      pch = 19,
      cex = 1.8
    )

    text(
      input$xnew,
      prob_nueva(),
      labels = paste0("  p = ", round(prob_nueva(), 3)),
      pos = 4
    )
  })

  output$resultado <- renderPrint({
    clase <- ifelse(
      prob_nueva() >= input$umbral,
      1,
      0
    )

    cat("Logit =", round(input$b0 + input$b1 * input$xnew, 4), "\n")
    cat("Probabilidad =", round(prob_nueva(), 4), "\n")
    cat("Umbral =", input$umbral, "\n")
    cat("Clase predicha =", clase)
  })

  output$interpretacion <- renderText({
    if (prob_nueva() >= input$umbral) {
      "La probabilidad supera el umbral, por lo que la observación se asigna a la clase 1."
    } else {
      "La probabilidad no alcanza el umbral, por lo que la observación se asigna a la clase 0."
    }
  })
}

shinyApp(ui, server)

5.13 Laboratorio interactivo: probabilidad estimada COVID-19

El simulador usa coeficientes estimados previamente con la muestra educativa. Su propósito es mostrar el funcionamiento matemático de una regresión logística; no es una calculadora clínica ni un instrumento de diagnóstico.

#| '!! shinylive warning !!': |
#|   shinylive does not work in self-contained HTML documents.
#|   Please set `embed-resources: false` in your metadata.
#| standalone: true
#| viewerHeight: 760
#| components: [viewer]

library(shiny)

ui <- fluidPage(
  titlePanel("Simulador educativo de regresión logística COVID-19"),

  sidebarLayout(
    sidebarPanel(
      sliderInput("edad", "Edad", 0, 100, 50, step = 1),
      checkboxInput("neumonia", "Neumonía registrada", FALSE),
      checkboxInput("diabetes", "Diabetes", FALSE),
      checkboxInput("hipertension", "Hipertensión", FALSE),
      checkboxInput("obesidad", "Obesidad", FALSE),
      checkboxInput("renal", "Enfermedad renal crónica", FALSE),
      sliderInput(
        "umbral",
        "Umbral de clasificación",
        0.05, 0.95, 0.50, step = 0.05
      )
    ),

    mainPanel(
      h3(textOutput("probabilidad")),
      textOutput("clasificacion"),
      plotOutput("grafica", height = "360px"),
      helpText(
        "Resultado exclusivamente educativo. No usar para decisiones médicas."
      )
    )
  )
)

server <- function(input, output, session) {

  prob <- reactive({
    eta <-
      -6.6586 +
      0.0856 * input$edad +
      4.6571 * as.numeric(input$neumonia) +
      0.7185 * as.numeric(input$diabetes) +
      0.3992 * as.numeric(input$hipertension) -
      0.0422 * as.numeric(input$obesidad) +
      2.6948 * as.numeric(input$renal)

    1 / (1 + exp(-eta))
  })

  output$probabilidad <- renderText({
    paste0(
      "Probabilidad estimada en la muestra: ",
      round(100 * prob(), 1),
      "%"
    )
  })

  output$clasificacion <- renderText({
    clase <- ifelse(
      prob() >= input$umbral,
      "Clase 1: defunción registrada",
      "Clase 0: sin defunción registrada"
    )

    paste(
      clase,
      "con umbral",
      round(input$umbral, 2)
    )
  })

  output$grafica <- renderPlot({
    edades <- 0:100

    eta <-
      -6.6586 +
      0.0856 * edades +
      4.6571 * as.numeric(input$neumonia) +
      0.7185 * as.numeric(input$diabetes) +
      0.3992 * as.numeric(input$hipertension) -
      0.0422 * as.numeric(input$obesidad) +
      2.6948 * as.numeric(input$renal)

    probabilidades <- 1 / (1 + exp(-eta))

    plot(
      edades,
      probabilidades,
      type = "l",
      lwd = 3,
      ylim = c(0, 1),
      xlab = "Edad",
      ylab = "Probabilidad estimada",
      main = "Curva logística según las características elegidas"
    )

    abline(h = input$umbral, lty = 2)
    points(input$edad, prob(), pch = 19, cex = 1.8)
    grid()
  })
}

shinyApp(ui, server)

5.14 Conclusión

La regresión logística es un modelo interpretable para clasificación binaria. El punto de corte permite ajustar el balance entre sensibilidad y especificidad.

5.15 Referencias fundamentales de la regresión logística

La formulación moderna de la regresión para respuestas binarias se relaciona con el trabajo de Cox (Cox 1958). Para profundizar en ajuste, interpretación, diagnóstico y aplicaciones del modelo logístico puede consultarse a Hosmer et al. (2013). Una presentación orientada al aprendizaje estadístico y a su implementación en R aparece en James et al. (2021).

Hosmer, David W., Stanley Lemeshow, y Rodney X. Sturdivant. 2013. Applied Logistic Regression. 3.ª ed. Wiley. https://doi.org/10.1002/9781118548387.
